# Decision record 0014: the codebase kept as a map, linked both ways to the developer handbook

- **Date:** 13 October 2026
- **Decided by:** project owner (maglesT), in the Phase 4 session: maintain the codebase so that its code is kept
  together by module, listed separately, and linked to the developer handbook (decision 0013).

## Decision

1. **Code grouped by module.** Each feature keeps its code together: its migrations (by source and range), its server
   feature folder, its contract file, its screens and its tests. The grouping already used (kernel, site services,
   recipe core, Tablets edition; one folder per feature) stays the rule, and a new feature gets its own folder rather
   than spreading into others.
2. **A code map, listed separately.** `docs/handbook/code-map.md` lists every module with all of its parts: migration
   files, database functions and triggers, server files, routes, contract file, screens, tests and the controls it
   enforces. It is generated by a script from the repository (migrations, the route table, the contract, the register)
   so it cannot go stale, and a test fails when it is out of date.
3. **Linked both ways.**
   - Handbook to code: every handbook section names the files and functions it explains, as links that open them.
   - Code to handbook: each package and feature README, and the header comment of each migration file, names the
     handbook page that explains it.
   - A link checker (a test) fails on a handbook link to a file or function that no longer exists, and on a module
     with no handbook page.
4. **Kept up as part of every change.** A slice that adds, moves, renames or removes code regenerates the code map,
   updates the handbook page and the links, and adds removals to the "removed and replaced" section (decision 0013);
   the slice's quick review checks it.
5. **Built with the handbook.** The code map, the link checker and the links for Phases 1 to 4 are made together with
   the handbook, after the Phase 4 focused mutation run (decision 0012) and before Phase 6.
