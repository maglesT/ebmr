# Decision record 0018: English only; slice 6h (languages) dropped

- **Date:** 15 October 2026
- **Decided by:** project owner (maglesT), in the Phase 6 session: first "regional language isnt needed cancel it",
  then "hindi also not needed just englishh".
- **Changes:** outline section 11 Phase 6 ("Hindi + one regional language") and the Phase 6 plan's slice 6h with its
  defaults D-P6h-*.

## Decision

1. The user interface, the master batch records and the printed records are in **English only** in v1. No Hindi and no
   regional language.
2. Slice 6h (languages) is dropped from Phase 6. Its exit list had no control, so the Phase 6 exit is unchanged.
3. Nothing already built changes: the existing message catalogue stays (it is the English text and the place a
   language would be added later), the Devanagari font already embedded for the PDF/A-3 true copy (D-P4-7) stays, and
   the rule that free text on US and EU batches is in English or carries a verified translation (decision 0001
   defaults) stays as it is.
4. A language can be added after v1 as its own piece of work (catalogue, approved MBR translations, the language shown
   recorded with each entry), if the owner asks.
