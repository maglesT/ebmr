## Lessons from 7t/7u (cost CI rounds; check before every push)

- Generated files: `pnpm handbook` + `handbook:check` (new migrations need a `-- Handbook:` line and a modules.yaml
  claim), `pnpm guides:lists` (new screens), `EBMR_WRITE_MATRIX=1` route-matrix test (new routes),
  `EBMR_WRITE_EXAMPLES=1` contract-examples test, SQL functions into `tools/sql-mutation/src/targets.ts`, new tagged
  tests synced (`--reporter=json --outputFile.json=.reports/partial.json` then
  `npx tsx tools/register/src/cli.ts sync-tests --results .reports/partial.json`), the execution store README's test
  list (`packages/recipe-core/src/execution/README.md`), then `pnpm vitest run tools`.
- Golden batches catch cross-record effects (a lock or hold after another lot's review). Set up the golden cluster
  (runpod-setup.sh lines 173-202 by hand) and run GB-T-01/03 for anything touching review, release, locks or bulk.
- E2E `act()` clicks and taps but does not wait for the answer: wait for the visible result before `as()` switches
  person. Local E2E here needs a browsers folder naming the preinstalled headless shell as build 1194
  (Playwright's pinned build): symlink `/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/
  chrome-headless-shell` as `chromium_headless_shell-1194/chrome-linux/headless_shell` and set PLAYWRIGHT_BROWSERS_PATH.
- Agent worktrees under `.claude/worktrees` make `pnpm lint` run out of memory: remove them after merging.
- The container restarts between wakes and stops PostgreSQL: `sudo pg_ctlcluster 16 main start`.
- CI on GitHub runners: about 80 minutes per full run. The RunPod pod would allow full local runs (owner's choice).
